## 3. 上位5案

13は1と重なるため、1に統合した（1の中の「お仕事回」として扱う）。同点の23点からは、性質の違う18・19・20を選んだ。

### A. 架空の惑星の生き物図鑑（#4・27点）
- **コンセプト**: 誰も見たことのない星の生き物を、自然ドキュメンタリーの語り口で紹介する。
- **想定視聴者**: 生き物・自然番組・SF・世界観ものが好きな層。
- **タイトル例**: 「霧の森で光る"呼吸する木"の正体」 / 「重力が2倍の星で、生き物はこう進化した」 / 「捕食者がいない湖に起きたこと」
- **毎回の差異**: 毎回新しい種と環境。種どうしの捕食・共生の関係図を少しずつ広げ、図鑑番号を振る。世界観設定（重力、大気、昼夜の長さ）が人間の独自の作り込みになる。
- **最大の難所**: 同じ生き物を複数カットで一貫させること。→ 1本を3〜4カットに抑え、最初に参照画像を固定する。カットごとにアングルを大きく変えすぎない。
- **伸びなかったら**: 地球の深海・絶滅動物の「もしも」（#3）に寄せる。

### B. 動物キャラの日常コント（#1＋#13・25点）
- **コンセプト**: 同じ動物キャラ（1〜2匹）が、ちょっとした仕事や日常で失敗する短いコント。
- **想定視聴者**: 動物・癒し・ゆるいコメディが好きな層。
- **タイトル例**: 「ペンギン駅員、初日」 / 「猫のカフェ店員、客が全員犬」 / 「カワウソ、引っ越しの段ボールに勝てない」
- **毎回の差異**: 毎回違う職業・場所・オチ。キャラの性格と口癖を固定し、それをネタにする。
- **最大の難所**: 毎回同じキャラに見せること。手元の作業。→ キャラの参照画像シートを最初に作る。手元のアップは避け、全身と表情で見せる。
- **伸びなかったら**: 職業ネタをやめ、キャラの日常ループ（無言・音のみ）に寄せて海外向けにする。

### C. 架空のレトロCM（#18・23点）
- **コンセプト**: 昭和〜平成初期風の、ありそうでない架空商品の15〜30秒CM。
- **想定視聴者**: レトロ・ネタ・シュールな笑いが好きな層。
- **タイトル例**: 「1983年の"月曜日を延期するスプレー"」 / 「家族で囲む"無限そうめん機"」 / 「通販番組：自動で言い訳を考える腕時計」
- **毎回の差異**: 商品アイデアそのものが毎回の独自性。年代ごとの映像の質感を変える。
- **最大の難所**: 画面内の文字（ロゴ・テロップ）が崩れる。→ 文字は生成させず、編集で後から入れる。実在ブランドに似せない。
- **伸びなかったら**: 「架空の通販番組」の長尺シリーズにまとめる。

### D. ことわざ・慣用句を文字どおり映像化（#20・23点）
- **コンセプト**: 「猫の手も借りたい」「目から鱗」などを文字どおり映像にして、本当の意味を一言添える。
- **想定視聴者**: 日本語・言葉遊びが好きな層、日本語学習者（推測）。
- **タイトル例**: 「"猫の手も借りたい"を本当にやってみた」 / 「"腹が立つ"を映像にするとこうなる」 / 「"顔が広い"人の1日」
- **毎回の差異**: 言葉ごとに映像の解釈が変わる。由来の小話を添える。
- **最大の難所**: 人体が変形する表現が、グロテスクや不気味になりやすい。→ 動物か、デフォルメした絵柄にする。
- **伸びなかったら**: 英語のイディオム版で海外向けにする。

### E. コメントで展開が分岐する連続ドラマ（#19・23点）
- **コンセプト**: 毎話の最後に2択を出し、コメントの多数派で次の話が決まる短い連続ドラマ。
- **想定視聴者**: 参加型・考察が好きな層。
- **タイトル例**: 「第1話：無人の駅で目覚めたロボット」 / 「第2話：右の扉を選んだ結果」 / 「第3話：みんなが選ばなかった方は…」
- **毎回の差異**: 視聴者の選択で毎回の展開が変わるため、量産判定とは逆の位置にある。
- **最大の難所**: 主人公の一貫性と、投稿間隔を空けられないこと。→ 主人公は顔のないロボットか動物にする。分岐はAかBの2択に絞る。
- **伸びなかったら**: 分岐をやめ、完結型の短編シリーズにする。

## 4. 推奨: A. 架空の惑星の生き物図鑑

**選んだ理由**
1. **AIの弱点が弱点になりにくい。** 生き物は架空なので、形の多少の崩れも「異星の生き物らしさ」として受け取られる（推測）。顔、口の動き、手、文字が不要。
2. **量産判定への備えが構造に入っている。** 毎回新種で、世界観の設定（重力、大気、生態系の関係）を人間が作り込む。ここがチャンネルの独自性になる。
3. **映像は言語に依存しない。** 日本語ナレーションで始めても、字幕や英語ナレーションで海外に広げやすい。
4. **Shortsと長尺がつながる。** Shortsで1種ずつ紹介し、長尺で「ある湖の生態系」のようにまとめる。

**弱いところ**
- 生き物そのものへの愛着は、キャラ型（B）より弱い。→ 図鑑番号と、何度も出てくる「看板種」を作って補う。
- 同じ発想のチャンネルが既にあるかは未調査。最初に `trend-researcher` で確認する。

## 5. 最初の5本で検証すること
1. **冒頭3秒の維持率**: 生き物を最初に見せる型と、環境から入る型のどちらが残るか。
2. **生き物のタイプの反応差**: かわいい系、不気味系、巨大系のどれが伸びるか。
3. **ナレーションの有無**: 合成音声ナレーションありと、字幕だけのどちらが良いか。
4. **コメントの内容**: 世界観への質問（「この星の他の生き物は？」）が出るか。出れば長尺化の根拠になる。
5. **制作の負荷**: 1本あたりの実時間と消費クレジット。週5〜8時間の仮定で続けられるか。
