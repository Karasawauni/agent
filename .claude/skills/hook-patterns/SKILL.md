# フックの型

冒頭3秒で「続きを見る理由」を作る。1本につき1つの型を選び、台本に型名を書く。

| 型 | 例 | 向いている題材 |
|---|---|---|
| 結論先出し | 「結論、○○は△△です」 | 解説・豆知識 |
| 問いかけ | 「なぜ○○は△△なのか？」 | 解説・雑学 |
| 意外な映像 | 日常にあり得ない1カットから始める | AI映像の強みを活かす |
| ビフォーアフター | 変化後を先に見せる | 変身・改善系 |
| カウントダウン/リスト | 「○○な3つのこと」 | まとめ系 |
| 共感 | 「○○あるある」 | キャラ・日常系 |
| 禁止・警告 | 「これだけはやめて」 | ノウハウ系 |

## 注意
- 煽りすぎ・誤認させる冒頭は避ける。
- フックの映像は、AIで破綻しにくい単純な構図にする。
- 運用で効いた型・効かなかった型はここに追記していく。
