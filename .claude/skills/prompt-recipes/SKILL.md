# プロンプトの型

## 画像（1枚目フレーム）
`被写体 + 状況/動作 + 場所 + 光 + カメラ/レンズ + 質感/色味 + 禁止要素`

例の骨格:
> [被写体の具体的な特徴], [動作], [場所], [時間帯・光], [ショットサイズ・アングル・レンズ], [色味・質感], no text, no watermark

## 動画（画像からの動画化）
`カメラの動き + 被写体の動き + 変化させない要素`

- 動きは1カットに1〜2個まで。
- カメラ: 固定 / ゆっくり前進 / パン / 軌道 など、具体的に書く。
- 「変えない要素」（顔・服・背景）を明記すると一貫性が上がる。

## 一貫性のためのルール
- キャラ・場所・色味は「固定要素」として全カットのプロンプトに同じ文で入れる。
- 画面内の文字、細かい手元、群衆は破綻しやすい。後から編集で足す。

## 記録
うまくいったプロンプトは、モデル名と一緒にここへ追記する。
