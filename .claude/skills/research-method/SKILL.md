# 調査の進め方

## 先に確認すること
- **モード**: 題材が未定なら「探索モード」、決まっていれば「深掘りモード」。
- **対象プラットフォーム**: 未指定なら TikTok / Reels / Shorts を対象にする。
- **調査の深さ**: 指定がなければ、検索は合計10〜15回程度に収める。

## 手順

### 探索モード（題材が未定）
1. 候補領域を5〜8個挙げる（例: 商品紹介、キャラ日常、雑学、ASMR風、ミニドラマ、ビフォーアフター）。
2. 領域ごとに「AI生成動画との相性」を評価する。基準は次の3点。
   - AIで破綻しにくいか
   - 1本あたりの制作コストが低いか
   - 量産しやすいか
3. 有望な上位3領域について、深掘りモードの手順1〜4を軽く行う。
4. 3領域を比較表にして、推奨を1つ選ぶ。

### 深掘りモード（題材が決まっている）
1. **流行の型を探す**: 検索クエリで直近の流行フォーマットを調べる。
2. **参考事例を集める**: 型ごとに、実際の動画・アカウントのURLを3件以上集める。
3. **AI動画の先行事例を探す**: 同ジャンルでAI生成動画が出ているか、反応はどうかを調べる。
4. **リスクを調べる**: プラットフォームの規約、AI開示ルール、権利上の注意。
5. 結果を `01-research.md` に整理する。

## 情報源の優先度
1. プラットフォーム公式（ヘルプ、ニュースルーム、クリエイター向けページ）
2. 利用可能なツールの一次データ（下記）
3. 信頼できる業界メディア・分析サービス
4. 個人ブログ・まとめ記事（参考扱い。単独の根拠にしない）

## 使えるツール
- `WebSearch` / `WebFetch`: 一般調査。
- Higgsfield の `tiktok_music_trending`、`get_presets`（source=viral）: 流行音源・流行エフェクトの確認。使えるかは実行時に確認する。
- 次のツールはクレジットを消費する可能性があるため、**ユーザーの承認なしに使わない**: `video_analysis_create`、`virality_predictor`、各種 generate 系。

## クエリの型
- 流行: `"<領域> TikTok trend <今年>"`、`"<領域> shorts 伸びる 型"`
- AI事例: `"AI generated <領域> viral tiktok"`、`"AI動画 <領域> 再生数"`
- 規約: `"TikTok AI-generated content label policy"`、`"YouTube altered or synthetic content disclosure"`
- 日付を入れて、古い情報を避ける。結果の公開日を必ず確認する。

## 根拠の強さ（必ず併記）
- **確認済み**: 公式情報、または一次データで直接確認できた。
- **報告あり**: 信頼できる二次情報に書かれている。
- **推測**: 自分の推論。根拠を一言添える。

## 調べられないこと（正直に書く）
- TikTok・Instagram の動画本体や再生数は、ログインが必要で `WebFetch` では取れないことが多い。
- 取れなかった場合は「取得不可」と書き、取れた範囲だけで結論を出す。数字を創作しない。
- 実際の再生数や反応を知りたい場合は、**ユーザーに手動でURLやスクショを渡してもらう**よう依頼する。

## 出力の追加ルール
- 調べたクエリの一覧と、採用/不採用の理由を、末尾に残す（再現できるように）。
- 調査日（今日の日付）を冒頭に書く。
