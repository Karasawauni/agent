# 公開前チェックリスト

各項目を OK / NG / 要確認 で判定する。

## 権利
- [ ] 実在人物に似た顔・声を使っていない
- [ ] 既存キャラ・商標・ロゴが映っていない
- [ ] 音源・BGMの利用権利を確認した
- [ ] 参照にした動画・画像の権利を侵害していない

## 規約・開示
- [ ] 投稿先のAI生成開示ルールに従っている
- [ ] 医療・金融などの断定的な主張がない
- [ ] 誇大・誤認を招く表現がない
- [ ] 事実の主張に出典がある

## 品質
- [ ] 手・顔・文字などの破綻がない（目視）
- [ ] カット間でキャラ・服装・場所が一貫している
- [ ] 冒頭3秒にフックがある
- [ ] 字幕が読める（UI領域と被らない）
- [ ] 音と映像がずれていない
- [ ] 尺・比率が投稿先の仕様に合っている

## 安全
- [ ] 不快・暴力・差別的な表現がない
- [ ] 未成年を扱う表現に問題がない

## 判定
- **合格**: NGなし、要確認が目視確認済み
- **条件付き**: 軽微な修正で解消できる
- **差し戻し**: 権利・規約のNG、または大きな品質問題
